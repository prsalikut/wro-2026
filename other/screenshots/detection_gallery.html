03

Field note — the green-cast bug

Root cause: the webcam ships with broken default controls — white balance disabled and gain maxed — which v4l2_camera applied verbatim, bathing every frame in green and making the detector see green everywhere. Forcing sane control values in the launch restored true colour. The pixel format was never the culprit; /image_raw is published as rgb8 regardless.
